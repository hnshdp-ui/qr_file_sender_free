iPhone 使用说明与本地打开限制

所有脚本和解码库都已包含在此文件中。页面不加载广告，不发送文件数据，也不请求网络资源。

局域网使用：在 Safari 打开接收服务器的 HTTPS 地址。接收页加载完成后，扫码、文件还原、校验和保存都在手机上进行。

离线使用：事先把本文件保存到 iPhone，并准备能运行 Python 的本地工具（如 a-Shell）。在文件所在目录执行 python3 -m http.server 8000 --bind 127.0.0.1，再用本机 Safari 打开 http://127.0.0.1:8000/receiver-standalone.html。此地址指向手机自身，不需要 Wi-Fi、移动数据或连接电脑。运行工具需提前安装。

文件 App、微信、邮件的 HTML 预览不等于 Safari 网页，可能无法执行脚本或调用摄像头。普通的 http://电脑IP 地址通常无法使用摄像头。若无法运行本地工具，需另行准备离线 Web App 或原生接收 App。

接收完成并通过 SHA-256 校验后，点击下载 ZIP；若 Safari 提供分享功能，可选择“存储到文件”。刷新或关闭页面会丢失当前接收进度。暂停摄像头会保留本页进度。

建议电脑先使用 run_sender.cmd "文件夹路径" --fps 8。接收稳定后再逐步提高帧率。
