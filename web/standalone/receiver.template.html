手机接收说明

请用手机浏览器打开 GitHub Pages 的 HTTPS 接收页，例如 Android 上的 Chrome 或 iPhone 上的 Safari。扫码、文件还原和校验均在手机上完成。

接收完成并通过 SHA-256 校验后，点击“下载 ZIP”保存文件。浏览器支持文件分享时，还会显示“分享 ZIP”。刷新或关闭页面会丢失当前接收进度。暂停摄像头会保留本页进度。

建议电脑先使用 run_sender.cmd "文件夹路径" --fps 8。接收稳定后再逐步提高帧率。
